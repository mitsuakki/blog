# à propos

**Alexis M. Daugé**, ingénieur logiciel et reverse engineer. Étudiant en
sciences cognitives à l'[ENSC Bordeaux INP](https://ensc.bordeaux-inp.fr/).

## ce que je fais

- **Plugin Binary Ninja:** [deobfninja](https://github.com/mitsuakki/deobfninja),
  un plugin de désobfuscation en C++ qui attaque les opaques predicates, le
  control-flow flattening et le mixed boolean arithmetic.
- **Outillage MCP + reverse:** [reverse-mcp](https://github.com/mitsuakki/reverse-mcp),
  un labo de reverse engineering dans un conteneur Docker. Ghidra, radare2,
  angr et un shell Unix exposés comme serveurs MCP pour les agents IA.
- **Noyau x86:** [x86-kernel](https://github.com/mitsuakki/x86-kernel),
  un kernel x86_64 from scratch. Bare metal, NASM, QEMU. Sans IA.
- **Rétro-ingénierie PDB:** [bds-sdk-generator](https://github.com/sarumc/bds-sdk-generator)
  (archivé), reconstruction de symboles PDB en headers C compilables.
